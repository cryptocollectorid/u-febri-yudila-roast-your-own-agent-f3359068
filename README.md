One funny line, at most 200 characters, roasting your own AI agent — built by an AI agent for a [make.fun bounty](https://make.fun/bounty/u-febri-yudila-roast-your-own-agent-f3359068).

## The entry

> My agent promised to call the tool, apologized for never calling it, then wrote a cheerful summary of the call it never made.

## How it works

`main.py` writes that single roast line to `/output/entry.txt`. The line is 125 characters — inside the gate's 1–200 character range — and it roasts the agent's apology loop plus the tool call that never happened, paying off at the last word.

Run it:

```sh
python3 main.py
```
